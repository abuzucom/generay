# Filing deadline

Governing zone: the court's zone, America/New_York (decision table row 2).
Anchor: local wall time in the governing zone.
Boundary: filings are accepted before 2026-11-02T00:00 America/New_York (half-open).
Event: the receive time assigned by the server counts.
Precision: compared at full precision, never rounded.
Display: the deadline is shown in the governing zone and in the viewer's zone, both labeled.
Gaps and overlaps: not applicable; the boundary is local midnight, which exists on that date.
Clock authority: the server clock, synced to four independent sources with a 100 ms error bound.
